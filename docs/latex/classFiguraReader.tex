\doxysubsection{Detailed Description}
Classe responsável por ler figuras geométricas de um arquivo de texto. 

A classe \mbox{\hyperlink{classFiguraReader}{Figura\+Reader}} interpreta comandos de um arquivo de texto e cria objetos das classes derivadas de \mbox{\hyperlink{classFiguraGeometrica}{Figura\+Geometrica}}. Esses objetos são armazenados em um container interno e podem ser utilizados para manipular um objeto da classe \mbox{\hyperlink{classSculptor}{Sculptor}}.
