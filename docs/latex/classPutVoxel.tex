\doxysubsection{Detailed Description}
Classe para adicionar um único voxel a um objeto \mbox{\hyperlink{classSculptor}{Sculptor}}. 

A classe \mbox{\hyperlink{classPutVoxel}{Put\+Voxel}} é derivada de \mbox{\hyperlink{classFiguraGeometrica}{Figura\+Geometrica}} e implementa a operação de adição de um único voxel. O voxel é definido por suas coordenadas {\ttfamily (x, y, z)} e sua cor é especificada pelos valores RGBA.
