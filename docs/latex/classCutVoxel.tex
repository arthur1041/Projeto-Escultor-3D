\doxysubsection{Detailed Description}
Classe para remover um único voxel de um objeto \mbox{\hyperlink{classSculptor}{Sculptor}}. 

A classe \mbox{\hyperlink{classCutVoxel}{Cut\+Voxel}} é derivada de \mbox{\hyperlink{classFiguraGeometrica}{Figura\+Geometrica}} e implementa a operação de remoção de um voxel específico identificado por suas coordenadas {\ttfamily (x, y, z)}.
