\doxysubsection{Detailed Description}
Classe abstrata para representar figuras geométricas. 

A classe \mbox{\hyperlink{classFiguraGeometrica}{Figura\+Geometrica}} define uma interface para figuras geométricas que podem ser desenhadas em um objeto \mbox{\hyperlink{classSculptor}{Sculptor}}. Classes derivadas devem implementar o método draw para especificar como a figura será desenhada.
