\doxysubsection{Detailed Description}
Classe para adicionar uma esfera a um objeto \mbox{\hyperlink{classSculptor}{Sculptor}}. 

A classe \mbox{\hyperlink{classPutSphere}{Put\+Sphere}} é derivada de \mbox{\hyperlink{classFiguraGeometrica}{Figura\+Geometrica}} e implementa a operação de adição de uma esfera. A esfera é definida pelo seu centro {\ttfamily (xcenter, ycenter, zcenter)} e pelo raio {\ttfamily radius}. Sua cor é especificada pelos valores RGBA.
