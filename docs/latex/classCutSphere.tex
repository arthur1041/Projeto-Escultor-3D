\doxysubsection{Detailed Description}
Classe para remover uma esfera de um objeto \mbox{\hyperlink{classSculptor}{Sculptor}}. 

A classe \mbox{\hyperlink{classCutSphere}{Cut\+Sphere}} é derivada de \mbox{\hyperlink{classFiguraGeometrica}{Figura\+Geometrica}} e implementa a operação de remoção de uma esfera. A esfera é definida pelo seu centro {\ttfamily (xcenter, ycenter, zcenter)} e pelo raio {\ttfamily radius}.
