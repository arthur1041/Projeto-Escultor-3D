Detailed Description

Classe para remover uma esfera de um objeto Sculptor.

A classe CutSphere é derivada de FiguraGeometrica e implementa a operação de remoção de uma esfera. A esfera é definida pelo seu centro (xcenter, ycenter, zcenter) e pelo raio radius.
