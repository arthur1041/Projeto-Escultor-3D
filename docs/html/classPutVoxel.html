Detailed Description

Classe para adicionar um único voxel a um objeto Sculptor.

A classe PutVoxel é derivada de FiguraGeometrica e implementa a operação de adição de um único voxel. O voxel é definido por suas coordenadas (x, y, z) e sua cor é especificada pelos valores RGBA.
