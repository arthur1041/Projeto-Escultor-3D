Detailed Description

Classe responsável por ler figuras geométricas de um arquivo de texto.

A classe FiguraReader interpreta comandos de um arquivo de texto e cria objetos das classes derivadas de FiguraGeometrica. Esses objetos são armazenados em um container interno e podem ser utilizados para manipular um objeto da classe Sculptor.
