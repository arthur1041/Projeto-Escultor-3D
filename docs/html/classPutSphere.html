Detailed Description

Classe para adicionar uma esfera a um objeto Sculptor.

A classe PutSphere é derivada de FiguraGeometrica e implementa a operação de adição de uma esfera. A esfera é definida pelo seu centro (xcenter, ycenter, zcenter) e pelo raio radius. Sua cor é especificada pelos valores RGBA.
