Detailed Description

Classe para remover um paralelepípedo de um objeto Sculptor.

A classe CutBox é derivada de FiguraGeometrica e implementa a operação de remoção de um paralelepípedo definido pelas coordenadas (x0, x1), (y0, y1) e (z0, z1). A região especificada terá todos os voxels desativados no objeto Sculptor.
