Detailed Description

Classe para manipular uma matriz tridimensional de voxels.

A classe Sculptor permite criar e modificar esculturas digitais tridimensionais usando uma matriz de voxels. Além disso, oferece suporte para exportar a matriz no formato OFF para visualização externa.
